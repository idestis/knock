Notes
{{- if eq .Values.store.type "valkey" }}
  - Door registrations are in Valkey (Secret {{ .Values.store.valkey.existingSecret }}): door ownership survives
    restarts. Knocks and live sessions are still in the pod: a restart or upgrade ends every live session.
{{- else }}
  - State is in memory (store.type=memory): one replica, and a restart or upgrade ends every live session
    and forgets every door. Hosts win their door ids back with signed claims, which need a stable
    KNOCK_TOKEN_SECRET. Use store.type=valkey to keep doors across restarts.
{{- end }}
